# Filosofía de diseño — goozarap

## Principios

- Ratio-first UI — no note names; smooth↔tense maps to complexity.
- Voice as universal instrument.
- Local-only ML — per-song, no cloud.
- Layered crates; deps point inward.

## Contexto

Music from ratios and Euclidean patterns; voice→instrument; per-song local influence models.

## Trade-offs explícitos

Este proyecto prioriza coherencia con los principios anteriores sobre conveniencia ad-hoc.
Cuando una decisión contradice un principio, debe documentarse como ADR o RFC.

## Relación con el ecosistema

- Proyecto independiente.
