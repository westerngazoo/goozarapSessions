# Recorrido del código — goozarap

Guía orientada a desarrolladores para entender dónde vive cada responsabilidad.

### 1. Hum-to-riff

Record → YIN pitch + onset → snap to ratio grid → K-S synth.

### 2. Beat

Euclidean E(k,n) templates → synthesized kit.

### 3. Session

Stems + takes + arrangement → WAV mixdown.

### 4. Influence

Reference tracks → feature extract → local adapter training.

## Punto de entrada recomendado

Empieza por el README del proyecto y el módulo/crate principal listado en la documentación de arquitectura.
